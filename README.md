# Оценка качества вина

Приложение на Streamlit предсказывает вероятность того, что вино
получит экспертную оценку не ниже 7

### Ссылки на приложение

- [Открыть приложение](https://wine-quality-app-dqiay5kwpj57xk6sbo68ar.streamlit.app)
  
## Окружение

Приложение проверено локально на Python 3.14.2
Версии библиотек указаны в requirements.txt

## Запуск

В терминале в папке wine_app:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Команда активации окружения выше предназначена для macOS и Linux
В Windows используйте `.venv\Scripts\activate`

После запуска откройте Local URL, указанный в терминале

## Возможности

- Оценка одного вина по 12 признакам
- Просмотр метрик, матрицы ошибок, ROC- и PR-кривых
- Загрузка CSV с несколькими винами и скачивание прогнозов
- Просмотр коэффициентов модели

Порог меняется в боковой панели. Начальное значение загружается
из config.json. Модель внутри приложения не обучается

## Файлы

- app.py — код приложения
- model.joblib — обученный пайплайн- StandardScaler и LogisticRegression
- config.json — выбранный на валидации порог
- test.csv — тестовая выборка для отображения метрик
- requirements.txt — версии библиотек
- README.md — инструкция запуска

## Загрузка CSV

Файл должен содержать столбцы:

fixed_acidity, volatile_acidity, citric_acid, residual_sugar,
chlorides, free_sulfur_dioxide, total_sulfur_dioxide, density,
pH, sulphates, alcohol, is_red.

Все значения должны быть числовыми без пропусков.
is_red: 0- белое вино, 1- красное
Столбец target не требуется
Разделитель- запятая, десятичный разделитель- точка
Пример файла можно скачать во вкладке пакетного предсказания

## Кеширование

Модель загружается через st.cache_resource, который сохраняет
один объект модели для повторного использования.

Таблицы и вероятности на тесте кешируются через st.cache_data,
который возвращает копии сохранённых данных.

Без кеширования joblib.load заново читал бы модель с диска
при каждом действии пользователя. При изменении порога
вероятности на тесте не пересчитываются: обновляются решения
и зависящие от них метрики.
